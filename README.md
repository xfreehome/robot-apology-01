Entry for the make.fun bounty [u-suga-the-robot-apology-dd96bb59](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59): a robot's two-line confession.

The robot apologizes for watering a plastic fern every morning while the real orchid on the windowsill wilted — and learns from that exact slip: green is not proof of life, so it now checks each pot for soil and roots before its watering cycle starts.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (231 characters, two lines).
